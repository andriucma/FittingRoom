# RandomTryOn: handoff

A 360° virtual try-on. The user records themselves turning in a circle; we pick frames by body angle, dress each frame in garments from a Shopify store with GPT Image, and show a drag-to-rotate result plus an optional smooth video.

## What's in here

| Path | What |
|---|---|
| `tryon-app/` | **The app** (Next.js 16 + a Python local-models service). Start here: `tryon-app/README.md`. |
| `docs/PROJECT_LOG.md` | Full history: every experiment, cost, problem → cause → fix, rejected approaches, open issues. **Keep it updated.** |
| `docs/openai/` | Downloaded OpenAI docs (GPT Image 2.6, image prompting, Decisions API, Images reference). |
| `scripts/` | The original prototype CLI scripts (try-on, angle extraction, SAM 3 alignment, Omni, compositing, viewer server). The app re-implements these; they still work for experiments. |

| `IMG_8204.mov` | Sample 360° spin video (the app's "Use sample video" button uses it). |
| `.env.example` | Which API keys / settings are needed. **Real keys are not included.** |

Excluded from the zip and regenerated by setup: `node_modules`, Python venvs, `.next`, model weights, `tryon-app/public/mediapipe`, the `data/` folder (videos, runs, SQLite catalog), and `work/` (prototype experiment outputs).

## API keys you need

| Variable | Needed for | Where to get it |
|---|---|---|
| `OPENAI_KEY` | **Required.** GPT Image 2.6 try-on (`gpt-image-2.6-flare` / `-sunburst`) and the Decisions API (`gpt-6-luna`) that tags products and picks the default department | https://platform.openai.com/api-keys (the org must have access to both models) |
| `GEMINI_API_KEY` | Optional. Gemini Omni smooth video. A billing-enabled project is required (Omni has no free tier). | https://aistudio.google.com/apikey |
| `SHOPIFY_STOREFRONT_URL` | Not a secret: the default store seeded into the catalog (e.g. `https://gymsharkusa.myshopify.com`) | — |

The Shopify catalogs are read from the stores' public `/products.json`; no Shopify key is needed.

## Setup (macOS, Apple Silicon)

```bash
brew install node python@3.12 ffmpeg       # Node 24+, Python 3.12, ffmpeg
cp .env.example .env.local                 # fill in OPENAI_KEY (and GEMINI_API_KEY for Omni)
cd tryon-app
ln -sf ../.env.local .env.local
npm install                                # + postinstall: in-browser pose model and WASM runtime
npm run setup:python                       # Python venv + SAM 3 weights (~1 GB, one time)
npm run dev                                # open http://localhost:3000
```

**Smoke test after setup:**
1. `curl localhost:3000/api/health` should show `localModels.ok: true` and `keys.openai: true`.
2. Open `/`, then click "Already have a video? Upload it instead", then **Use sample video**.
3. Pick a store. Gymshark is seeded and takes about 1 minute to tag the first time.
4. Pick a top and a bottom, then click **Generate**. A 30° step costs about $0.86; a 60° step about $0.40.

- Try-on runs with original and studio backgrounds.
